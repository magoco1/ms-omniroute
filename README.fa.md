## 🧭 ایده کلی

```
ابزار چت (یک Base URL + یک کلید) ──▶ ورکر Cloudflare (ثابت) ──▶ استودیو (OmniRoute)
```

> **ورکر برای چیه؟** گیت‌وی مدل‌اسکوپ هدر `Authorization` را برای توکن خودش برمی‌دارد و ایمیج آماده هم `X-Frame-Options: DENY` می‌فرستد (داشبورد داخل iframe دیده نمی‌شود). ورکر هر دو را حل می‌کند.

## 🛠️ راه‌اندازی قدم‌به‌قدم (فقط مرورگر)

### قدم ۱ — ساخت استودیو
نوع **Docker** + سخت‌افزار رایگان. همین ریپو (`master`) را پوش و Deploy کنید.

### قدم ۲ — Secrets (فقط صفحه استودیو، هرگز داخل کد!)
`JWT_SECRET` (رندوم طولانی)، `INITIAL_PASSWORD` (پسورد داشبورد — **فقط بوت اول** اعمال می‌شود!)، `REQUIRE_API_KEY=false`، `API_KEY_SECRET`.

> تغییر بعدی سکرت پسورد، پسورد ذخیره‌شده را عوض نمی‌کند؛ با پسورد اول وارد شوید و از داخل داشبورد عوض کنید.

### قدم ۳ — باز کردن داشبورد
هاست `ms.fun` داخل iframe خالی می‌ماند (سخت‌گیری خود ایمیج). از داشبورد Tunnel را **یک‌بار** Enable کنید و از آدرس تونل یا ورکر استفاده کنید.

### قدم ۴ — ساخت کلید API
داشبورد → API Keys → کلید (`sk-...`). بعد از تست بچرخانید.

### قدم ۵ — آدرس ثابت با ورکر خودتان
ساخت ورکر با `workers/bridge-template.js`، ست کردن `TUNNEL_URL` و سکرت `MS_TOKEN`. در برنامه‌ها: Base URL ثابت ورکر + کلید. با تغییر تونل فقط `TUNNEL_URL` را آپدیت کنید. تونل quick با هر redeploy می‌میرد — دوباره Enable کنید.

### قدم ۶ — اضافه کردن کلیدهای پرووایدر
داشبورد → Providers. موقع ریت‌لیمیت خودش سوییچ می‌کند.

## 🔒 امنیت
- هیچ سکرت واقعی در ریپو نیست. `tests/` و `docs/` به‌خاطر کلیدهای نمونه حذف شده‌اند (اصلش در upstream هست).
- کیپ‌الیو کم‌تکرار است ولی دور زدن sleep ممکن است خلاف ToS باشد — مسئولیت با شماست.
